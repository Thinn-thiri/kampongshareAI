# KampongShare AI

A community donation and volunteer platform for Singapore (hackathon prototype).
Organizations post what they need, donors offer items, volunteers sign up for events,
and AI helps rank the most urgent needs. Humans always make the final decisions.

The full specification is in [REQUIREMENTS.md](REQUIREMENTS.md). The build order is in [BUILD_STEPS.md](BUILD_STEPS.md).

## Tech

- Plain HTML + JavaScript (with `// @ts-check` + JSDoc) and Alpine.js
- Tailwind CSS v4, built with the Tailwind CLI. This is the only build step.
- Supabase for the database and logins
- Netlify for hosting and serverless functions (the AI calls run there)

## Run it on your computer

You need [Node.js](https://nodejs.org) (LTS) and Git.

1. Install the tools:
   ```
   npm install
   ```
2. Copy `.env.example` to `.env` and fill in your own values. `.env` is never committed.
   "What can you give?" matching uses `NVIDIA_API_KEY` (from build.nvidia.com); without it, the page shows category buttons instead.
   For postal code → map pin lookup, also add a free [OneMap](https://www.onemap.gov.sg/apidocs/register) account as `ONEMAP_EMAIL` / `ONEMAP_PASSWORD`. It's used only by the `geocode-postal` function.
3. Put your Supabase Project URL and **anon** key in `js/config.js`. The anon key is public by design. Never put the service role key there.
4. Start two terminals:
   ```
   npm run dev:css      # rebuilds css/style.css whenever you save
   npx netlify dev      # local web server + functions
   ```
5. Open http://localhost:8888. Don't open the HTML files by double-clicking them.

To see every shared component, open http://localhost:8888/styleguide.html.

`npm run build` makes the minified CSS. Netlify runs it automatically when deploying.

## Folder layout

```
*.html                 one page per screen (index, signup, login, dashboards, public pages)
styleguide.html        every shared component with sample data
src/input.css          Tailwind source: theme colours + shared component classes (edit this)
css/style.css          generated by Tailwind (never edit, not committed)
js/                    config.js, supabase.js, auth.js, ui.js (shared by every page)
img/                   icons and images
netlify/functions/     server code (AI scoring, matching, captions, share previews)
supabase/migrations/   database schema and later changes
supabase/reset_database.sql   wipes the database (test data only)
```

## Privacy (PDPA)

The app follows Singapore's Personal Data Protection Act. It collects only what it needs, asks for consent, never sends personal data to the AI, and lets users view, correct and delete their data. See REQUIREMENTS.md section 4 and `privacy.html`.

**Data breaches:** in a real launch, a data breach that is likely to cause significant harm to the people affected must be reported to the **Personal Data Protection Commission (PDPC)**, and to the affected users, promptly. This must happen **within 3 calendar days** of assessing the breach as notifiable. A **Data Protection Officer (DPO)** would be appointed and named in the privacy notice as the contact for privacy questions.

All sample data in this project is fictitious.
